# Product Startup Landing Page

## Project Overview

This project is a responsive single-page product/startup landing page created using **HTML, CSS, and JavaScript**. It demonstrates modern front-end design principles by combining clean layouts, smooth animations, and interactive elements to provide an engaging user experience.

## Features

* Responsive single-page layout
* Hero section with a call-to-action button
* Features section with interactive feature cards
* Call-to-action (CTA) section encouraging user engagement
* CSS hover transitions on buttons and feature cards
* CSS `@keyframes` animation for a floating hero element
* Scroll-triggered reveal animation using the **Intersection Observer API**
* Modern pastel color palette and responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Intersection Observer API
* Google Fonts (Poppins)

## Animations Used

* **Hover Transitions:** Buttons and feature cards smoothly change appearance when hovered.
* **Keyframe Animation:** A floating decorative element in the hero section creates visual interest.
* **Scroll Reveal:** Feature cards animate into view as they enter the viewport using the Intersection Observer API.

## Animation Design Decisions

Animations were used to improve the user experience without overwhelming the interface. Hover effects provide clear visual feedback during interaction, while the floating animation adds subtle movement to the hero section. The scroll-triggered reveal guides users through the content naturally by introducing feature cards as they become visible. I avoided excessive animations to keep the page professional, responsive, and easy to navigate.
